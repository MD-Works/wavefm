How to publish
  1. Click Generate JSON then Copy to Clipboard
  2. Go to your GitHub repo → open channels.json
  3. Click the ✏️ pencil edit icon
  4. Select all and paste your new JSON
  5. Click Commit changes
  6. Cloudflare auto-deploys in ~30 seconds ✅
